NoReact – Allergen Detection App

The NoReact mobile application was developed for the purpose of assisting users in the detection of allergens in food products. This objective is pursued by means of intelligent image recognition and real-time AI assistance. The application was built using Android Studio (Java), integrated with Roboflow for image classification, Firebase for authentication and database, and Gemini API for AI chat functionality.

Year: 2025
Role: Backend Developer
Course: Mobile Programming
Repository: https://github.com/Ikannilaaa/NoReact.git

Project Description

NoReact is a smart mobile application designed to assist users, especially those with food allergies, in identifying potential allergens in their meals. The application provides comprehensive features to ensure food safety and user convenience.

Key Features

  • Home Screen: Users can explore a list of common allergens and browse foods categorized as allergen-free (e.g., egg-free). Each food item is also linked to a recipe for user reference.
  • AI Chat: Integrated with Gemini API, this feature allows users to interact with an AI assistant for allergy-related questions, food suggestions, or recipe customization.
  • Food Scanner: Users can scan food by capturing an image via camera or selecting one from the gallery. The app then predicts the name of the food and lists any potential allergens based on trained models from Roboflow.
  • History: Stores a log of previously scanned foods, including prediction results and allergen detection, allowing users to track their scans over time.
Java Android Studio Roboflow Firebase Gemini API

RAST – Judging Student Submission Tool

RAST is a web application that helps lecturers review student essay submissions through automated text analysis. It combines NLP and Transformer models to assess answers from several angles — AI-generated content detection, semantic relevance, peer similarity, and writing style. Built with React and FastAPI, the system presents clear analytical insights that support more informed academic review.

Year: 2026
Role: Full-Stack Developer & Machine Learning Engineer
Project: Undergraduate Thesis (Final Year Project)
Repository: https://github.com/Aliyah-Pattoza/Tugas-Akhir.git
Demo: Video Demo (Google Drive)

Project Description

RAST was built to help lecturers run an initial review of essay submissions more efficiently. By combining several text analysis methods, it highlights answers that may need closer attention.

It does not decide whether academic integrity has been violated. Instead, RAST acts as a decision-support tool — presenting clear indicators that lecturers can review and interpret themselves.

Key Features

  • AI-Generated Content Detection: Uses a fine-tuned DeBERTa model to estimate how likely a response is AI-generated.
  • Semantic Relevance Analysis: Uses Sentence-BERT (all-mpnet-base-v2) to measure how closely a student answer aligns with the expected meaning of the question.
  • Peer Answer Similarity Analysis: Compares submissions across students to surface unusually similar answers that may need follow-up review.
  • Stylometric Analysis: Looks at writing patterns and linguistic traits to provide additional signals during evaluation.
  • Evaluation Dashboard: Shows results in an interactive dashboard so lecturers can inspect scores, open individual answers, and prioritize what to review next.
  • Report Generation: Exports evaluation reports in PDF and Excel for documentation and further assessment.

Inkluvia – Accessible Learning Platform

Inkluvia is a web platform that helps visually impaired teachers access and manage digital learning materials. It converts PDF documents into accessible formats through AI-powered processing, screen reader support, and Braille device integration. Built with Laravel and AI services from Gemini and OpenAI, it also uses MQTT to deliver content to EduBraille devices.

Year: 2025
Role: Backend Developer
Project: GEMASTIK – Tomodotchi Team
Repository: https://github.com/Aliyah-Pattoza/Inkluvia.git
Demo: YouTube Demo

Project Description

Inkluvia makes it easier for visually impaired teachers to prepare teaching resources independently. By combining document processing, AI, and assistive technology, it turns conventional digital files into formats that work better with screen readers and Braille devices.

Key Features

  • PDF Document Processing: Teachers can upload PDF materials, which are processed with PyMuPDF to extract content for further conversion.
  • AI-Powered Content Processing: Gemini analyzes the extracted content, while OpenAI helps refine the output into a clearer, more accessible structure.
  • Screen Reader Compatibility: Converts mathematical and special symbols into representations that are easier to understand through assistive reading tools.
  • Braille Integration: Uses MQTT to send processed materials to EduBraille devices for refreshable Braille access.
  • Accessible User Interface: Designed for both visually impaired and sighted teachers, with keyboard navigation and screen reader support in mind.

PETET – Petualangan Teman TK

PETET is a Java-based 2D educational game that invites the player, a kindergartner, on an adventure to collect school supplies while avoiding obstacles to reach the school with the best score.

Year: 2023
Role: Game Developer
Course: Object-Oriented Programming
Repository: https://github.com/Aliyah-Pattoza/PBO-FP.git

Project Description

The PETET game is a two-dimensional educational adventure game developed using Java for the Object Oriented Programming course. The game in question simulates a kindergartner's journey to school by collecting various school supplies scattered along the way. Each item contributes to the player's score. The objective of the game is to navigate a grid-based map while evading obstacles such as mud and water puddles, which result in a points deduction when stepped on. The objective of the game is to reach the school building, which serves as the culmination of the game and displays the total score based on the items collected. The game places emphasis on object-oriented principles, including inheritance, encapsulation, and polymorphism, in the management of game entities such as items, obstacles, characters, and scoring logic.
